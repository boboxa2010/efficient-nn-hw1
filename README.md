# Efficient NN HW1

## GPU and software

- Google Colab, T4
- Deps: vanilla collab env + `pynvml`

## Результаты

FLOPs близко совпадает с показаниями профилировщика, потому что специально считали только те операций, которые он умеет трекать.
Оценка пиковой памяти в целом работает ожидаемо, хотя и наблюдаются сильные отклонение (я лично видел выделения каких-то супер больших временных буферов и воркспейсов при посчете свертки 5x5).
Latency тоже работает достаточно прилично, хоть и часто занижает оценку, более точную, наверное, можно получить если брать максимум для каждого слоя.
Оценка энегрии тоже близка к изменениям.
